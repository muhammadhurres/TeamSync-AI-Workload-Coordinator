# TeamSync AI — Workload Coordinator

![TeamSync AI](teamsync%20ai%20thumbnail.png)

A Python FastAPI web app that helps teams balance tasks by matching work to team members’ skills and available hours.

## Features

- Team lead and candidate dashboards
- AI-assisted task coordination, with an offline mock mode
- Workload fairness score and task assignment explanations
- Responsive HTML, CSS, and JavaScript interface

## Run locally

```bash
pip install -r requirements.txt
python app.py
